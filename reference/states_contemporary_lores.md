# U.S. state boundaries

The U.S. Census Bureau provides [cartographic boundary
files](https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html)
for current U.S. boundaries. This package has only the low-resolution
contemporary state boundaries. Other census boundary files are provided
by and documented in the USAboundariesData package.

## Usage

``` r
states_contemporary_lores
```

## Format

An object of class `sf` (inherits from `data.frame`) with 52 rows and 13
columns.

## See also

For citations for the other Census boundary files provided by the
USAboundariesData package, see the `census_boundaries` documentation in
that package.
